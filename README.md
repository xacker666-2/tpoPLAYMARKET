
## Название приложения

**ZALA** — приложение для просмотра телевидения от РУП «Белтелеком».  
Рейтинг в Google Play: **2.6 ★**

# Вывод
По результатам тестирования приложения **ZALA (Smart ZALA)** для мобильных устройств были выявлены многочисленные критические ошибки. Приложение **не соответствует** заявленным требованиям и не может считаться стабильным продуктом.
Ключевые проблемы:
- массовые вылеты на этапе запуска и во время просмотра;
- отсутствие нормальной обработки сетевых ошибок;
- избыточные запросы разрешений, ведущие к аварийному завершению;
- неадаптированный интерфейс, особенно на телевизорах;
- чрезвычайно низкая производительность.
